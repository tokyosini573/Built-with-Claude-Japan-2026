# ちかくに v2 の変更一覧

v1（`apps/demo_matching`）の結果 `runs/demo_matching/report.json` の離脱理由のテーマ（`drop_themes`）をもとに直したもの。
直したのは、どれかのテーマに根拠があるものだけ。エンジンのルール（`rules/`）・判断のプロンプト（`teppuri/judge/prompts`）は変えていない。
A案・B案の条件（地域、期間、キャンペーン日数、ターゲット、チャネルと予算、動画のプラットフォーム・アカウント数・本数・制作費）は v1 と同じ。

区分の意味:
- **画面・仕様（判断に効く）**: 画面・広告・説明文の変更。エンジンの入力の数字は変わらず、Claude の判断（higher / similar / lower）を通してだけ結果に効く。
- **エンジンに直接効く**: app.yaml の数字の変更。判断をやり直さなくてもエンジンの計算が変わる。

## 2. エンジンの数字に関わる変更（画面の改善と分けて）

| 項目 | v1 | v2 | エンジンでの効き方（`teppuri/engine/simulate.py`） |
|---|---|---|---|
| `pricing.monthly_jpy` | 3980 | 2980 | **直接効く。** 決済の確率に (価格 / 基準価格)^(−弾力性 × 価格感度) を掛ける（基準価格 = `rules/presets.yaml` matching の `reference_monthly_jpy` mid 3,135円、弾力性 `price_elasticity`）。売上も 1人あたり 2,980 円で計算される。決済者は増える方向、1人あたりの売上は 25% 減る方向に同時に効く |
| `gates[0].review_hours` | 24 | 12 | **計算は変わらない。** 待ち日数 = ceil(時間 / 24) なので 24時間も12時間も1日。`gates.baseline_wait_days`（1日）を超えた日数にだけ `wait_loss_per_day` が掛かるので、どちらも待ちによる減少はゼロ。判断のプロンプトには「審査の待ち時間: 12 時間」として見えるので、判断を通してだけ効く |
| `pricing.free_trial_days` | 0 | 0（変えない） | matching のプリセットでは無料体験の日数は計算に使われない（`trial_days` は subscription / habit だけ）。入れると判断にだけ見えて、エンジンは初日から課金する計算のままになり、仕様と数字が食い違うので、無料お試しは入れなかった |
| `pricing.who_pays` | male | male（変えない） | — |

価格の決め方: 2,980 円は、エンジンが価格の基準に使うカテゴリの決済者1人あたり月額（3,135 円、出典 `[MG25Q3]/[MG25Q4]`）をわずかに下回る値。v1 の 3,980 円はこれを約 27% 上回っていた。値は結果を見て決めたものではない（エンジンの確認は形式のチェック1回だけ）。

## 3. 対応しなかったテーマ・入れなかったもの

- **女性は無料で支払いと無関係**（A.dr16, A.dr25〜27, A.dr29, B.dr26, B.dr27）: 女性が払わないのは仕様どおりで、離脱ではないので変えない。
- **無料お試し・初月割引**: 上のとおり matching のプリセットでは計算されない（初月だけの価格も表せない）。代わりに、エンジンが表せる「月額の値下げ」と、判断に効く「定型のあいさつ1通は無料」に分けた。
- **口コミ・利用者の声・実績の数字**: 発売前の架空アプリなので、利用者の声や会員数・マッチ数などは入れない。v1 の動画 v2 の「再現」も同じ理由でやめた。
- **本人確認の書類・顔写真の要件**（`docs_ja`）: 安全の仕組みそのものなので変えない。伝え方（理由・削除の方針・待つ間にできること）だけを直した。
- **ターゲット・予算・媒体の配分**: 比較のため v1 と同じ。対象外の層への露出は、動画の中身（独身の方向けと明示）だけで対応した。

## 4. ファイル

- 画面 `screens/01〜05.png`、広告 `ads/a1〜a3.png`、動画の見本 `ads/v1〜v3.png` は `src/` の HTML から `tools/render.mjs` で作った。v1 の B案用の静止画広告（b1〜b3）は app.yaml で使っていないので v2 には入れていない。
- 再生成: `cd apps/demo_matching_v2/tools && npm install && npx playwright install chromium && npm run render`（v1 の `tools/node_modules` を使うなら `ln -s ../../demo_matching/tools/node_modules node_modules` してから `node render.mjs`）。
- 判断（`runs/demo_matching_v2/decisions.json`）はまだない。比べるには v1 と同じ手順で判断・ペルソナを出してからエンジンを30回実行する。
