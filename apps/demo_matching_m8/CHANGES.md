# 対照実験 m8: 見た目だけ変えた版（プラセボ）

v1（`apps/demo_matching`）から出発し、**v2 と同じくらいの量の目に見える変更（17項目）** を入れた。ただし v1 の離脱理由のテーマ（`runs/demo_matching/report.json` の `drop_themes`）には**どれも触れない**。色・書体・イラストの描き方・部品の形・並び順・同じ意味の言い換え・ボタンの文言だけ。

判断が「変更の量」や「新しい見た目」に反応して上がるなら、この版も v1 より良く出る。テプリが中身を見て判断しているなら、v1 とほぼ同じになるはず。

変えていないもの: 価格 3,980円、審査の最大時間 24時間、無料お試しなし、登録のステップ数（3）と入力項目、本人確認の書類、審査中にできること（見る・いいね）、承認前はメッセージ不可、男性の無料の範囲（いいね1日5回）、広告の問いかけの形（問いかけは問いかけのまま言い換え）、「同じ駅を利用」「職場が近い」「市区町村が見える」などの表示、動画の中身（ナレーション）、A案・B案の条件。

v1 のテーマ（参考）: 広告の伝え方への抵抗 / 対象外の層への露出 / 住まい・職業の入力への警戒 / 身分証の提出と審査待ちの負担 / 承認前に話せないもどかしさ / 男性の月額料金の重さ / 女性は無料で支払いと無関係 / 口コミ・継続する理由の弱さ
