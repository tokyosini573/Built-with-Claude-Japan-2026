# 架空の日本1万人（15〜79歳）

`japan_10k.csv` は、公開統計の分布から作った架空の日本人 10,000人です。実在の人ではありません。
`representatives.csv` は、似た人をまとめたグループ（クラスタ）と、その代表1人です。

```bash
.venv/bin/python -m teppuri.population.build            # 2つの CSV を作り直す（数秒）
.venv/bin/python -m pytest tests/test_population.py     # 出典との一致を確かめる
```

- LLM は使っていません。乱数のシードは固定（`SEED = 20261108`）で、同じコマンドで同じファイルが出ます。
- コード: `teppuri/population/build.py`。前処理: `teppuri/population/prep_census2020_70plus.py`（下の「追加した加工ファイル」）。
- 出典の詳細（表番号・公表日・加工・検証）は `data/DATA_SOURCES.md`。出典ファイルは `data/sources/` にあります。

## 作り方

1. **骨格（都道府県 × 性 × 年齢）**: 2025年国勢調査の 47都道府県 × 男女 × 5歳階級（13階級）= 1,222セルの人口に比例して 10,000人を配り、最大剰余法で合計をちょうど 10,000 にします（乱数なし）。各セルの人数と「人口比例の理論値」の差は 1人未満です。各歳は 5歳階級の中で一様に引きます。
2. **残りの属性**: 出典 CSV の条件付き分布から付けます。条件グループ（例: 女性 × 20代）ごとに、
   区分の人数を「期待値を保つ丸め」で決めてから（`floor(n·p)` を確定し、端数は端数に比例して重複なしで抽選）、グループ内でランダムに割り振ります。
   そのため、各グループの比率は出典と **1人分以内** で一致します（テストで確認）。
3. **重み**: 全員同じ `weight = 9,680.6585`（= 96,806,585 ÷ 10,000）。合計は 2025年国勢調査の 15〜79歳人口 96,806,585人です。
4. **代表人物**: 下の「代表人物」の節。

### 式の補足

- **就業形態**（DATA_SOURCES 2-4）: `q(都道府県) = 2020国勢調査の都道府県比率 × (労働力調査2025の全国比率 ÷ 2020国勢調査の全国比率)` を合計1に再正規化。労働力調査の「70歳以上」（80歳以上を含む）は、2020年国勢調査の全国の `70〜74歳 ÷ 70歳以上` と `75〜79歳 ÷ 70歳以上` の比を掛けて分けます。
- **所得**（DATA_SOURCES 2-5）: 就業者（正規・非正規・自営等）は就業構造基本調査の16階級から勤労所得の階級を引き、階級内で一様に金額を引きます。自営等は、2020年国勢調査の「自営等のうち業主の割合」で「自営業主の分布」と「有業者全体の分布」（役員・家族従業者の代用）を混ぜます。年金は全員に年齢別の分布（受給なしを含む）から引き、金額を足します。勤労所得も年金もない人は `none` です。
- **SNS**（DATA_SOURCES 2-8）: 人口全体の率 `P(k|a,s) = P_media(k|a) × r(k,a,s)`、`r = u(k,a,s) ÷ Σ_s w(a,s)·u(k,a,s)`（u = モバイル社会研究所の「認知者のうち利用」、w = 国勢調査の性比）。LINE・YouTube は表5-1-1 の「男女別 ÷ 全体」を年齢に関係なく掛けます。スマホ保有者の中での率は `min(1, P(k|a,s) ÷ P_gen(スマホ|a,s))`（P_gen = この人口に付けたスマホ保有率、通信利用動向調査 第24表の性×年齢帯）。こうすると人口全体の SNS 率が出典 P(k|a,s) と一致します（上限1で切れるセルを除く、限界3）。SNS どうしの相関はガウシアンコピュラ（ρ = 0.5、DATA_SOURCES 5章 限界3 の設計値）で入れています。各グループの SNS 別人数は変えず、「どの人が使うか」の重なりだけに効きます。

## 代表人物（`representatives.csv`）

**役割（契約 v2）**: 判断は 1万人全員が受けます（`decisions.json` は `person_id` 単位）。クラスタは「Opus が書くペルソナ要約の単位」で、同じクラスタの人は同じ要約（代表人物の人物像）を共有します。判断が人単位で無いときだけ、エンジンはクラスタの判断を使います。

1. 年齢帯（10代後半 / 20代前半 / 20代後半 / 30代前半 / 30代後半 / 40代 / 50代 / 60代 / 70代）× 性 × 都市規模 × **婚姻**（未婚 / 既婚 / 離別・死別）でグループに分けます。マッチングアプリでは婚姻が最も効く属性なので、既婚の代表が未婚の人の分まで代表しないようにしています。
2. 8人未満のグループは次の順で統合します（性と都市規模はまたがない）。
   1. 同じ年齢帯・性・都市規模の「既婚」と「離別・死別」をまとめて **「既婚・離死別」** にする（どちらかが8人未満のとき。15グループ）
   2. それでも小さければ、同じ性・都市規模・婚姻（未婚 / 結婚経験あり）の隣の年齢帯と合わせる（例: `町村・20代後半〜30代後半・未婚女性`、`地方都市・10代後半〜20代前半・既婚・離死別女性`）
   3. 未婚と結婚経験ありを混ぜる統合は、今のデータでは起きていません（テストで確認）
   
   結果は **119グループ**（8〜382人、中央値 53人）。内訳は 未婚 52 / 既婚 27 / 離別・死別 25 / 既婚・離死別 15。
3. 各グループの中を、性向5指標（low=0 / mid=1 / high=2）で k-means に分けます。クラスタ数は全体で 400 になるようグループの人数に比例させ、8人未満のクラスタは同じグループ内で性向の重心が最も近いクラスタに統合します。結果は **410クラスタ**（8〜68人、中央値 24人）。
4. 代表人物は、性向の重心に最も近い人（同点なら年齢がクラスタの中央値に近い人、次に `person_id` が小さい人）です。
5. `label_ja` は「都市規模・年齢帯・婚姻性別・特徴」。特徴は、クラスタの性向の平均が全国平均から最も離れている指標を言葉にしたもの（同じグループ内で同じラベルになるときは2つ目の特徴を足す）。例: `大都市・20代後半・未婚女性・新しいもの好き`、`地方都市・50代・既婚男性・新しいものに慎重・節約志向`。

| 指標 | high 側 | low 側 |
|---|---|---|
| trait_price | 節約志向 | 出費をためらわない |
| trait_novelty | 新しいもの好き | 新しいものに慎重 |
| trait_privacy | 個人情報に敏感 | 個人情報をあまり気にしない |
| trait_wom | 口コミ重視 | 口コミに左右されない |
| trait_ad_aversion | 広告嫌い | 広告に抵抗なし |

`cluster_weight` はクラスタの重みの合計（実際の人数）。`japan_10k.csv` の `cluster_id` と一致します。

## 限界

1. **条件付き独立**: 性×年齢（一部は都道府県×性×年齢）が同じ人の中では、属性どうしの相関を入れていません。例えば同じ「東京都・女性・30〜34歳」の中で、都市規模と就業、所得とスマホ、SNS と性向、性向どうしは無関係に付いています。例外は「配偶関係×世帯類型」（結合分布）、「就業形態→所得」、「スマホ→OS・SNS」、SNS どうし（ρ = 0.5 の設計値）です。
2. **都市規模は他の属性に効かない**: 都市規模は都道府県×性×年齢から付けますが、配偶関係・就業・スマホ・SNS は都市規模で変わりません（大都市と町村で同じ率）。
3. **SNS は上限1で切れるセルだけ出典に届かない**: スマホ非保有者の SNS はすべて false にしているため（DATA_SOURCES 5章 限界3 の「スマホ非保有者の LINE・YouTube 利用」は入れていない）、出典の利用率がスマホ保有率（通信利用動向調査 第24表、無回答を分母に含む保守的な値）を超えるセルでは、スマホ保有者全員が使う形になり、人口全体の率は保有率で止まります。該当セル（性×年齢帯: 出典 → 生成の上限、%）:
   - LINE 女性: 15-19 97.6→93.2、20-29 99.0→93.4、30-39 99.2→94.7、40-49 97.8→94.4、50-59 96.8→93.1、60-64 93.2→90.5、65-69 93.2→84.8、70-74 78.8→72.0、75-79 78.8→57.4
   - LINE 男性: 15-19 95.2→91.5、20-29 96.4→92.1、30-39 96.6→93.0、40-49 95.4→93.3、50-59 94.4→92.8、65-69 90.8→87.7、75-79 76.8→64.9
   - YouTube 男性: 15-19 98.4→91.5、20-29 99.7→92.1、30-39 97.3→93.0、40-49 94.9→93.3

   それ以外のセル（X・Instagram・TikTok の全セル、YouTube の女性と男性50歳以上、LINE 男性 60-64・70-74）は、人口全体の率が出典と2人以内（スマホと SNS の2段の丸め）で一致します。例: 20代 Instagram 出典 82.6% → 生成 82.5%、10代 TikTok 67.9% → 67.6%、20代 X 73.4% → 73.3%。切れるセルの一覧は `build.sns_capped_cells()` で出せます。
4. **古い年・混ざった年**: 都道府県別の就業形態は 2020年国勢調査のパターン、勤労所得は 2022年（2022年以降の賃金上昇は反映していない）、年金は 2024年所得、性向は 2022〜2025年の調査です。OS の性差は 2022年の文章（「3〜9ポイント」）からの推定です。
5. **近似指標**: 価格感度・広告への抵抗感・個人情報への不安は代理指標です（DATA_SOURCES 5章 限界4）。`retired` は「60歳以上の非労働力『その他』」の代理です。
6. **所得の近似**: 階級内は一様分布。最上位の「1500万円以上」は 1500万円、年金の「300万円以上」は 300万円として扱っています。学生・家事の人のアルバイト収入は入れていません（就業形態が `student` / `unemployed_homemaker` の人は勤労所得なし）。所得の分母は所得不詳を除いた有業者です。
7. **年齢帯の粗さ**: SNS・OS・性向は10歳階級、メディア調査の「10代」は 13〜19歳の値を 15〜19歳に使っています。各歳は5歳階級内で一様です。
8. **小さいセル**: 10,000人では1セル平均約8人で、小さい県の一部のセル（例: 鳥取県 男性25〜29歳 ≈ 1人）は0人か1人です。都道府県単位の分析は誤差が大きくなります。
9. **重みは一律**: 全員 9,680.6585人。セルごとの丸め（1人未満）は重みで補正していません。
10. **代表人物のラベル**: 特徴語はクラスタの性向の平均から機械的に作ったもので、クラスタの全員に当てはまるわけではありません。
