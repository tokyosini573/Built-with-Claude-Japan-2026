# テプリ データ出典一覧（DATA_SOURCES）

最終更新: 2026-11-06

## 0. この文書について

テプリは、統計に基づいて作った「合成日本」の仮想人口 10,000人（15〜79歳）の上で、アプリのローンチをリハーサルするシミュレーターです。この文書は、仮想人口とシミュレーションエンジンに入っているすべての数値について、出典・加工方法・利用条件・限界をまとめたものです。

### 基本ルール

> **人口と数値はすべて公開統計・公開資料から。LLMは数値を作らない。**

- 仮想人口 10,000人は、政府統計と公開調査の分布から一度だけ生成し、リポジトリに固定します。この生成に LLM は使いません。
- Claude が担当するのは、仮想人口 10,000人の一人ひとりがアプリの画面や広告を見たときの判断（「このカテゴリのアプリ平均より 高い／同程度／低い」）とその理由だけです（1万人全員を判断します。ペルソナの要約はグループ単位）。判断を数値に変えるのはエンジンで、下記のベンチマーク値に倍率を掛けます。倍率は統計ではなく設計上のパラメータで、ルールファイルに書いてバックテスト前に固定します。
- 出典がない値（例: D90 リテンション、アプリのインストール頻度）は「仮定」として扱い、画面と本書の「5. 限界」に明記します。

### 表の見方

- **信頼度**: 1次 = データを持つ主体が自ら出した資料（政府調査、プラットフォーム公式、上場企業の開示、計測・広告・課金SDK企業の自社データレポート、媒体社の料金表）。2次 = 1次資料を報じた記事。3次 = 代理店・SaaS のブログ記事の「相場」や、他人のデータの再引用。
- **画像読取**: その値が PDF 本文のテキストではなく、チャートや表の画像（ラベル）から読んだ値であることを示します。
- **地域**: 日本／APAC（RevenueCat の定義では日本・韓国・オーストラリア・ニュージーランド）／グローバル／地域未記載 を区別します。

## 1. 仮想人口の構成

1人が持つ属性と、それを決める出典は次のとおりです。エンジンは (都道府県 × 性 × 年齢 × 都市規模) のセルに 10,000人を割り当て、残りの属性をセルごとの条件付き分布から引きます。

| まとまり | 属性 | 主な出典 |
|---|---|---|
| 基本 | 年齢、性別、都道府県、都市規模、配偶関係、世帯類型、就業形態、所得 | 国勢調査 2025、労働力調査 2025、就業構造基本調査 2022、国民生活基礎調査 2025 |
| デジタル | スマートフォン保有、OS、SNS別利用、利用時間、鉄道通勤、大学生 | 通信利用動向調査 2025、情報通信メディア利用時間調査 2025年度、モバイル社会研究所、国勢調査 2020、学校基本調査 2025年度 |
| 傾向（サイコグラフィック） | 価格感度、新しもの好き、個人情報への不安、口コミ・レビュー依存、広告への抵抗感 | 消費者意識基本調査（2022・2023・2025年度）、通信利用動向調査 2025 |

### 2-12. 傾向（サイコグラフィック）5指標

5指標はいずれも、政府（または政府委託）調査の**性別 × 10歳年齢階級の回答分布**から、各人に high / mid / low を1回だけ確率的に割り当てます。個人を測定した値ではありません。

**共通の加工**: 「無回答」「経験したことがない・分からない」を分母から除いて 100 に再正規化。5段階は原則「とても＋ある程度」= high、「どちらともいえない」= mid、「あまり＋ほとんど」= low。回答が片側に 70%以上偏る設問だけは、上位1段のみを high にした（指標ごとに明記）。個人情報への不安の設問だけは**4段階（中立なし）**で、mid（「どちらかといえば不安」）は「中間」ではなく「弱い不安」。無回答を除く処理は無回答が無作為だという仮定で、高齢層ほど影響が大きい（個人情報への不安の70代は無回答が男性 9.4%・女性 13.6%）。80歳以上の行は使わない。5指標は性 × 年齢の条件付きで互いに独立と仮定。結果: `trait_mapping_sex_age.csv`。

   - 年齢確認の段階での離脱率: なし。代理指標は [CFA24] の「利用者のうち身分証明書の登録 65.9%」だけです。eKYC ベンダーの自社主張（撮影開始者のうち離脱「3.0%以下」）はありますが、分母が「撮影を始めた人」で独立検証もないため、エンジンには使いません。
   - アプリのインストール頻度（月あたりの新規インストール数）: 公的・準公的資料なし。ダウンロード済みアプリ数（2022年）に比例する仮定パラメータです。
   - 40歳以上のマッチングアプリ利用・態度: 性×年齢の政府統計なし。
   - その他: 日本デーティングアプリのブランド別有料会員数と男女比の公式値、デーティングの有料/オーガニック比率、オンボーディング完了率、フリマの出品・初取引率、K-factor、Education・Productivity の体験→有料とリテンション、X・YouTube の公式最低予算、交通広告の視認確率、学食トレイの月間接触人数。
   - 性×年齢の SNS 別利用率（政府統計）、2026年の OS 性×年齢表: 公開されていません（下の推定で代用）。
3. **推定・仮定パラメータ**
   - OS の性差（女性 +d/2・男性 −d/2、d = 5.6ポイント）は 2022年の文章による推定です。
   - SNS の男女比はモバイル社会研究所の Web 調査から借りており、LINE・YouTube は年齢に関係なく同じ男女比を掛けています。
   - SNS 間の相関（ガウシアンコピュラ、ρ≈0.5）、スマホ非保有者の LINE・YouTube 利用、判断を数値に変える倍率は、データではなく設計上の値です。
   - Pairs の決済者数は公開されておらず、本書では推計していません。
4. **代理指標**
   - 「価格感度」は「お金はなるべく使わないようにしている」（支出を抑える態度）、「広告への抵抗感」は「表示・広告の内容は信用できる」の逆方向（広告だけでなく商品の表示も含めた不信）です。価格弾力性や広告回避の行動を測った値ではありません。
   - 「個人情報への不安」は「インターネットを利用する際の不安の有無」（ネット利用時の不安全般。詐欺・ウイルスなども含む）で代用した**近い代理指標**です。個人情報そのものを聞いた設問ではありません。不安を感じる人の 89.8% が個人情報・利用履歴の漏えいを挙げることを補助根拠にしています。4段階（中立なし）の設問なので、mid は「中間」ではなく「弱い不安」です。
   - 「サブスク・課金意向」はサブスク契約経験とデジタルコンテンツ購入経験で代用しており、実際のアプリ課金率ではありません。サブスク契約経験は無回答を「経験なし」として計算しており、無回答を除いて再正規化する他の指標と扱いが違います（70代で差が大きい: 男性 56.4% → 67.6%、女性 54.3% → 67.9%）。
   - 引退は「60歳以上の非労働力『その他』」による代理指標です。
   - 習慣系ツールのリテンションは Finance（家計簿の近似）と Utilities を使っています。
5. **小さい調査セル**
   - 消費者意識基本調査の性×年齢セルは n=73〜523（15〜19歳は約70〜125）で、セルごとの比率の誤差はおよそ ±5〜12ポイントです。集計は無加重で、回収率は性・年齢で違います。
   - メディア調査は N=1,800（10代 140人）です。
   - マッチングアプリの成人既婚者の一部セルは n=140 程度です。
   - 10,000人の割り当てでは小さいセル（例: 鳥取県 男性25〜29歳 ≈ 1.1人）が0人か1人になります。都道府県単位の分析は誤差が大きくなります。
6. **定義の違い**
   - モバイル社会研究所白書の SNS 利用率の分母は「各サービスの認知者」で、人口全体ではありません。同研究所の「スマートフォン比率」の分母は携帯電話所有者です。
   - 通信利用動向調査のスマホ保有率は無回答を分母に含み、高齢層で低めに出ます（75〜79歳女性の無回答 18.5%）。無回答を除いた値を感度分析に使います。
   - 個人情報への不安はインターネット利用者、口コミ依存はインターネット利用者、サブスクはインターネット購入者が母集団で、非利用の高齢者に同じ分布を当てると過大・過小になりえます。消費者意識基本調査は日本国籍者のみが対象です。
   - [L19]・[LS19]・[LD22] の登録・購入転換率が有料（広告経由）設置ベースであることは、どのレポートにも明記がなく推定です（いずれも Liftoff のネットワークデータで、Methodology にはアプリ数・期間・表示・クリック・設置・イベント数だけが書かれています）。オーガニック流入の転換率は公開資料がありません。
   - **[LD22] の「ITA-Purchase」（設置→購入）は、同じチャートの費用と合いません。** 日本は公表値 0.57%（p.18 の見出し文とチャートラベル）ですが、同じパネルの CPI $7.02 ÷ CPA-Purchase $82.43 ≈ 8.5% になります（0.57% なら CPA-Purchase は約 $1,232 のはず）。米国 2.17%（計算 9.6%）、ドイツ 0.55%（2.9%）、韓国 1.01%（10.9%）、p.17 の地域別（APAC 0.66% に対し 6.2% など）も同じずれ方をします。一方、同じチャートの「ITA-Registration」（日本 46.61%）は費用からの計算と一致します。レポートは ITA-Purchase を定義していません。そのため 0.57% は公表値のまま記録しますが、**エンジンには使いません**（設置 → 有料は [L19] の 5.4% / 5.4% / 6.3%）。[L19] の 5.4%（購読）との約10倍の差も、この定義の問題で説明できる可能性があります。
   - 日本ゲームの CPI は Adjust 中央値 $1.3〜1.5 と Liftoff 平均 $5.5 で約4倍違います。レポートは理由を説明していません。エンジンでは単一値ではなく範囲で示します。
   - 同じレポート内でも数値がずれています: [A24] のEC D30 は要約（p.9）と本文（p.45）で異なり、本文・チャートの値（5〜6%）を採用。[L19] のショッピング登録率は 31.9%（図表）と 32.9%（本文）。モバイル社会研究所の 2026年スマホ比率はページ本文 98.3%、CSV 98.1% です。
   - RevenueCat 2025 の初回更新率 61.7% は同じページ内で説明が矛盾し、プラン期間も不明なため、エンジンには使いません（日本の 62% は [RC24] の値）。
   - 交通広告の CPM の分母は乗車延べ人数（往復は2回）で、到達率を延べ人数に掛けるのは粗い近似です。TRAIN TV「8,400万人以上」は下限表現のため、81円は上限側の値です。
   - 大学生数はキャンパス所在地ベースで、短期大学・専門学校は含みません。
   - 世帯類型の「子と同居する親」は同居の子だけを数えます。未婚のひとり親は「親と同居する未婚の子」に、三世代世帯の親は「拡大家族・その他」に分類されます。
7. **代理店ブログの広告単価**: SNS の CPM・CPC・CPI の大半は代理店ブログの相場（3次）で、互いに書き写した跡があります（Instagram の「CPI 100〜250円」が複数の記事に同じ形で出る、など）。「独立した出典が2つ」でもサンプルと期間は非公開です。TikTok の CPV は出典間で10倍違います。代理店相場の CPI（100〜250円）と計測会社の実測（$5.5 前後）も大きく違います。
8. **地域ラベル**: 日本単独の値がない指標には APAC（日本・韓国・オーストラリア・ニュージーランド）、グローバル、地域未記載の値を使っています。Braze の D30 は地域・期間とも記載がなく、low 側だけに使いました。YouTube の CTR 0.65% は地域未記載の海外ベンチマーク（一部は 2018年データ、元の単位はドル）で、日本の実測ではありません。Meta・TikTok の CTR は米国中心のグローバル値です。Pairs の売上には台湾・韓国事業が含まれ、決済者数・RPP は Azar（グローバルのビデオチャット）と合算した Match Group Asia の値です。
9. **傾向指標は調査にもとづく分布で、個人の測定値ではない**: 各人の high / mid / low は、性×年齢セルの回答割合から確率的に割り当てたものです。実在の誰かを測ったものではありません。指標間の相関は公開集計表から推定できないため、性×年齢の条件付きで独立と仮定しました（実際には新しもの好きと口コミ依存などに相関がありうる）。5段階を high/mid/low にまとめる規則はテプリが決めたもので、別の規則なら比率が変わります。所得・職業・地域・学歴別の表は使っていません。
10. **調査方法の違い**: モバイル社会研究所の値は Web 割付調査で、ネットに親しい層が多めに出る可能性があります（高齢層は訪問調査との体系的な比較をしていません）。調査方法（郵送・訪問留置・Web）が混在するため、出典間で水準を直接比較できません。
11. **開けなかった資料**: Adjust ブログ（アクセス制限）、AppsFlyer のレポート本文（フォーム入力型）、Business of Apps（403）、Repro の元リリース（403）、サイバーエージェントの IR ライブラリ（JS描画）、AppsFlyer の国×カテゴリのベンチマークページ（JS描画）。これらにより良い数値がある可能性があります。
12. **独立検証の範囲**: 冒頭のとおり、調査文書 7本はすべて V1〜V4 の独立検証を受けました。それでも未検証のまま残る値があります: 全国都市交通特性調査（PDF を開けなかった。エンジンには不使用）、モバイル社会研究所のアプリ数調査の規模・時期、2026年の OS 性×年齢表や YouTube・LINE の性×年齢表が「公開されていない」という不在の主張など。モバイル社会研究所白書の値は PDF グラフのラベルを手で書き写したもので、V3 が照合して一致しましたが、転記である点は変わりません。検証で見つかった誤り（労働力調査の就業形態CSVの内職者の二重計上、通信利用動向調査の表番号のずれ、個人情報への不安の水準表示など）は修正済みです。
