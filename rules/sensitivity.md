## 読み取り

- 判断なし: 基準の「B が良い確率」は 0.07。A の決済者 p50 は仮定1つで最大 6.5 倍動き、最も効くのは「クリック→設置率（matching）」（94〜614 人）。 どの仮定を1つ動かしても、A/B の優劣は変わらない。
- 仮の判断あり: 基準の「B が良い確率」は 0.57。A の決済者 p50 は仮定1つで最大 7.5 倍動き、最も効くのは「クリック→設置率（matching）」（48〜364 人）。 **仮定1つで結論がひっくり返る**: matching 1日あたりマッチ確率（low = 0.1）、クリック→設置率（matching）（high = 0.28）、判断倍率（弱い（higher = 1.15, lower = 0.85））。 基準でも五分五分に近く、この組み合わせでは「どちらが良い」とは言えない。
- 運営中モード（値上げ）: 基準の「B が良い確率」は 1.00。A の決済者 p50 は仮定1つで最大 1.8 倍動き、最も効くのは「身近なクチコミ q」（29,574〜51,569 人）。 **仮定1つで結論がひっくり返る**: 価格弾力性（high = 1）。
- 判断倍率の行は、判断がない（全て similar）と結果が変わらない（倍率 1.0 のため）。「既存利用者の配分」「成熟期の月次解約率」「累計設置者」の行は、initial_state がない表では結果が変わらない（累計設置者の行は、ほかの表に基準の値をそのまま写している）。
- クリック→設置率は決済者の水準を最も大きく動かす。代理店相場（high）と計測会社の CPI（low・mid）の差がそのまま出ている。水準（何人）を言うときは、この幅を必ず添える。
- X クチコミは全国の X 利用者に届くので、全国で出す案ほど設置に変わりやすい（出荷地域を絞った案では地域外に届いた分が無駄になる）。q_x を大きくすると全国展開の案が相対的に有利になる。
- 運営中モードでは既存の利用者がクチコミの発信源になるので、クチコミの強さ q が水準（払い続けている人数）を最も動かす（約2倍）。クチコミは出典のない仮定なので、バックテストでまず確かめる値。累計設置者（ever_installed）も水準を約1.6倍動かすので、公開値があれば入力する。値上げ（B）で売上が上回る結論は、価格弾力性を high（1.0）にすると逆転する（値上げの判断は弾力性しだい）。
- 判断がある場合、A/B の優劣は判断倍率の大きさに強く依存する。バックテストで倍率を固定する前に、この表を見て倍率の幅を決める。
