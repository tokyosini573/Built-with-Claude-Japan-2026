- エンジン（運営中モードの修正）: 判断なしの試運転で、既存の決済者が月7.6%減る（新規1年目の率）、既存の利用者が1か月で4割減る、過去にやめた人を数えずクチコミが過大、という構造の問題が見つかった。成熟期の月次解約率（13か月目以降）、成熟期の曲線、累計設置者（ever_installed、推定つき）を入れた。事例の正解には合わせていない。
- エンジン（動画の大量投稿 organic_video、12d263a の固定後に追加・バックテスト未検証）: 広告費を払わない短尺動画を複数アカウントで毎日投稿するチャネルを、既存の計算を変えずに足した（organic_video の無い plan は結果が完全に同じことをテストで確認）。値はリポジトリ外の調査メモ（非公開）の表から入れた。最初の版では「アカウント間のばらつき」σ_between に調査の推計値（1.5〜2.4、いろいろなクリエイター全体のばらつき）を使ったところ、架空のマッチングアプリで「新しい10アカウント × 毎日1本 × 50日」の再生の**中央値**が1.4億回、日本人の視聴者が4,500万人になった。調査の事例（20アカウントで5,800万再生、創業者の自己申告＝成功例の上限扱い）を大きく超えていた。原因は二重計算: クリエイター全体のばらつきにはフォロワー数の差が既に入っているのに、テプリはフォロワーの成長を別の仕組みでも計算していた。σ_between を「同じ運営者の新しいアカウントどうしのばらつき」と定義し直し、出典がないので assumption（0.5 / 1.0 / 1.5）にした。直したあと中央値は約1,900万回、p90 は約1.5億回。成功例を10アカウント・50日に比例換算した約600万回と比べると、まだ p50 で約3倍、p90 で約25倍大きい。p90 を押し上げているのは、当たったアカウントがフォロワーを集めて再生が伸びる仕組み（再生 ∝ フォロワー^k、1再生あたりのフォロー）で、フォロワー効果を止めると p90 は約1,600万回になる。目安に合わせて値を動かすことはせず、そのまま残して記録した（どちらの値も仮定か推計）。
