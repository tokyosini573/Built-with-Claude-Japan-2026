# 試行錯誤の記録

開発中に試したこと、うまくいかなかったこと、変えたことを日付順に書く。

## 2026-11-06
- 設計を項目ごとに合意してから作り始めた（範囲、人口、エンジン、Claude の使い方、バックテスト）。
- 人口の出典は、調査エージェント5つと独立検証4回を経て `data/DATA_SOURCES.md` にまとめた。157か所を修正し、作り話の数字は見つからなかった。
- 公開サイトのインタビューは、実行時の費用と悪用対策を考えて、事前に作った質問と答えだけにした。
- エンジン: 1人 ≈ 9,680人なので、地図用の1回抽選を 0/1 にすると設置がほぼ0人になった。「この人が表す人数のうち何人が進んだか」を整数で抽選する方式に変えた。
- エンジン: マッチングの密度を「今アクティブな相手側」で数えると立ち上がりで初マッチがほぼ起きなかった（関門通過者の5%）。「関門を通ったプロフィールの累計」に変えた（約23%）。
- エンジン: リテンションを指数の和で近似したところ、D1〜D30 の補間の折れ目で最大25%ずれた。出典の点（D1・D7・D30）を強く合わせ、近似曲線そのものを使うことにした。
- エンジン（契約 v2）: 運営中のアプリから始めるモードを足した。既存の利用者に新規と同じ初期離脱を当てると、1日目に7割以上が消えて不自然だったので、「発売から一定ペースで獲得してきた」とみなした曲線の位置から続ける形にした。
- 人口: SNS 利用をスマホ保有者に条件付けるとき、割る数をメディア調査のスマホ保有率にしていたため、人口全体の SNS 率が出典より低く出た。割る数を「この人口に実際に付けたスマホ保有率」（通信利用動向調査 第24表）に揃えて一致させた。出典の率がスマホ保有率を超えるセル（主に LINE）は上限1で切れて不足が残り、`data/population/README.md` の限界3に書いた。
- 人口: 独立検証 V3 で、労働力調査の就業形態の派生 CSV が「内職者」を自営等に二重に足していたことが見つかった。修正して再生成した（女性・男女計の18セルが0.1ポイント超変化、最大0.29ポイント）。
- 人口: 代表人物のグループ分けに婚姻が入っておらず、既婚の代表が未婚の人の分まで代表していた。マッチングアプリでは婚姻が最も効く属性なので、年齢帯 × 性 × 都市規模に婚姻を足した（契約 v2）。
- 判断: 最初は代表人物（396グループ）の判断をグループ全員が受け継ぐ設計で、1グループ（実人口で数十万人）が同じ判断になり、グループ内の違いはエンジンの揺らぎでしか出なかった。判断を1万人全員に変え、代表人物はペルソナ要約の単位としてだけ残した（契約 v2）。50人 × 2案の Batch 実測（$0.032）で費用を確かめてから決めた。
- 判断: 試験実行で、地域外・既婚・高齢など対象から外れる人を lower とする判断が多かった。地域・ターゲットはエンジンが別に掛けるので二重に数えることになる。判断の意味を「その段階まで来たとき、カテゴリ平均と比べて進みやすいか」と決め、地域・SNS 利用・広告到達・密度を理由にさせない形にした（契約 v2）。
- 判断: レポートに数字を書かせない仕組みにした。Opus は本文に数字を書かず、engine.json から作った事実の表の ID（`{{A.totals.installs.p50}}` など）で引用する。コードが直書きの数字（算用・全角・漢数字、「二倍」「三割」など）と表にない ID を検査し、違反なら1回だけ書き直させ、それでも駄目なら止める。
- Claude Code: 実際のやり方を `.claude/` に形にした。担当ごとのサブエージェント8つ、Skills 3つ（ベンチマーク追加、リプレイ再生成、バックテストの固定順）、hooks 3つ（エンジン・ルール変更でテスト自動実行、`rules/*.yaml` の出典なし値を止める、予測のコミット前に正解ファイルへの書き込みを止める）。出典チェックは最初「同じ階層に source があること」だけを見たところ、`multipliers.yaml` の `traits.*.factor`（source が1つ上の階層）を5件誤検出したので、すぐ上の階層の source も認め、今回の書き込みで新しく増えた違反だけを止める形にした。
- エンジン（運営中モードの修正）: 判断なしの試運転で、既存の決済者が月7.6%減る（新規1年目の率）、既存の利用者が1か月で4割減る、過去にやめた人を数えずクチコミが過大、という構造の問題が見つかった。成熟期の月次解約率（13か月目以降）、成熟期の曲線、累計設置者（ever_installed、推定つき）を入れた。事例の正解には合わせていない。
