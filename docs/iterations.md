- わかったこと:
  - **名札の影響はほぼない。** 名札つき v2 と名札なし t5（中身は同じ）の差は、A案の決済者 −2、B案の設置 −70 など、むしろ名札つきの方がわずかに低かった。v2 の伸びは「v2」という名前のせいではない。
  - **悪化版は全指標・30回すべてで下がった。** 価格と審査時間（エンジンに直接効く数字）だけ変えた中間と比べても、判断の変化だけで A案の決済者 −10、設置 −652 だった（設置はエンジンの数字では変わらないので、すべて判断から）。
  - **プラセボも上がった。** 特に広告の段階: A案の設置 +198 は本物の改善（+213）とほとんど同じ。v1 の判断のまま install の判断だけ差し替えると +171 で、プラセボの伸びの大半は広告の判断から来ている。広告の判断は、中身が同じでも見た目・言い換えが変わると「平均より良い」寄りに動く（lower 73.8% → 70.0%）。登録より後の段階では差が小さく（決済者 +2 に対して本物の改善は +25）、見分けられていた。
  - P(良い)=1.00 は「同じ抽選値なので、小さな差でも毎回同じ向きに出る」ことを表すだけで、差の大きさではない。プラセボの A案の決済者 +2 も P=1.00 になる。
- 限界: 判断はすべて同じ Claude（Haiku 5.5）で、変更を作ったのも Claude。本物の利用者で効くかは確かめていない。対照は1つずつ（同じ種類の変更を何通りも試していない）。悪化版は判断にとって分かりやすすぎる変更で、「小さな悪化」を見分けられるかは確かめていない。
- 結論: テプリは「大きな改善」と「大きな悪化」は正しい向きに出した。登録から決済までの段階では見た目だけの変更に強くは反応しなかった。しかし**広告の段階（設置）は見た目だけの変更にも本物の改善と同じくらい反応する**ので、設置数の伸びだけでは改善の根拠にならない。
